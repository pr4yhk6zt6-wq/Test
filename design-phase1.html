ระบบแสดงกิจกรรม 3 ระดับ (กดดูได้ในเครื่อง)

A
Live Status Line — แถบเหนือช่องพิมพ์ บอกว่ากำลังทำอะไร + ขั้นที่เท่าไร + เวลาที่ผ่านไป แตะเพื่อกางไทม์ไลน์
B
Activity Timeline — ในตัวข้อความ พับได้ หัวข้อสรุป "ทำงาน 6 ขั้นตอน · 42 วินาที" · แต่ละขั้นมีไอคอน ชื่อภาษาคน สถานะ และเวลา
C
Detail Sheet — แตะขั้นไหนก็ได้ จะเปิดแผ่นล่างสุด แสดงคำค้น แหล่งข้อมูล ไฟล์ที่ได้ และข้อผิดพลาด (โค้ดดิบเฉพาะโหมด "ละเอียด")

ลองสลับ "ระดับกิจกรรม" เป็น น้อย แล้วดูว่าไทม์ไลน์ยุบเหลือบรรทัดเดียว และเป็น ละเอียด แล้วดูว่าแถบสถานะโชว์รายละเอียดย่อยเพิ่ม

ลองกดดู

  • แตะ แถบสถานะ เหนือช่องพิมพ์ → กาง/พับไทม์ไลน์
  • แตะ ขั้นตอนใดก็ได้ → เปิดรายละเอียดระดับ C
  • สถานะ ว่าง → การ์ดต้อนรับ + ชิปคำสั่งด่วน + สิ่งที่ทำได้
  • สถานะ สำเร็จบางส่วน → ขั้นที่ล้มเหลวต้องมีสาเหตุเป็นภาษาคน + ทางไปต่อ
  • สถานะ ข้อความยาวมาก → ย่อไว้ก่อน กด "แสดงทั้งหมด" ค่อยกาง
  • สลับ iPhone 7 · 375×667 เพื่อดูว่าเนื้อหายังอ่านได้บนเครื่องจริง (จอ 4.7")

กติกาที่บังคับใช้ทั้งดีไซน์

  • ไม่มีสปินเนอร์เปล่า — ทุกการรอมีข้อความบอกว่ากำลังทำอะไร
  • สถานะไม่พึ่งสีอย่างเดียว — มีไอคอน + ข้อความกำกับเสมอ
  • ไม่แสดงตัวเลขประมาณการ (เวลาที่เหลือ / ความมั่นใจ) ถ้าไม่มีข้อมูลจริงรองรับ
  • ศัพท์เทคนิค (ชื่อ tool, โค้ด, ดิบ ๆ) ซ่อนเป็นค่าเริ่มต้น
  • เป้าหมายการแตะ ≥ 44pt ทุกปุ่ม · คอนทราสต์ผ่าน AA ทั้ง Light และ Dark
