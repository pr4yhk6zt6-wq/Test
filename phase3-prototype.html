คำแนะนำการใช้งาน (Onboarding)

01

เห็นทุกขั้นตอนที่ Agent ทำ

Agent ไม่ทำงานลับหลัง — คุณเห็นทุกการค้นหา ทุกการเรียกเครื่องมือ และทุกไฟล์ที่สร้างได้เสมอ ผ่าน Live Status Line และ Timeline

02

ควบคุมได้ทุกเมื่อ

คุณหยุดงาน แทรกคำสั่ง แก้ไขแผน หรืออนุมัติได้ทุกขั้นตอน — ไม่มีการทำสิ่งที่มีผลกระทบโดยไม่ขออนุญาต

03

ปลอดภัยและโปร่งใส

Agent ไม่เห็นรหัสที่คุณพิมพ์ ไม่ทำตามคำสั่งแปลกจากเว็บ และบอกสาเหตุทุกครั้งที่ล้มเหลว — คุณเลือกได้ว่าจะดำเนินงานต่อหรือหยุด
