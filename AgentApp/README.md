# AgentApp — UI ที่สร้างจากแบบ (ดีไซน์ v2)

โฟลเดอร์นี้คือ **หน้าจอจริงของแอปใหม่** สร้างขึ้นจากแบบที่อนุมัติไปแล้ว (`design-phase1.html`, `design-phase2.html`,
`phase3-prototype.html`, `phase4-prototype.html`) โดย **ไม่ลาก UI เก่ามาดัดแปลง**

- ของเดิมในโฟลเดอร์ `Views/NewUI/` ถือเป็น **ประวัติ** — ไม่ได้ถูกเรียกใช้เป็นหน้าจอของบิลด์ใหม่
- "สมอง" ของแอปยังใช้ชุดเดิมที่ผ่านการทดสอบแล้ว (OpenRouter, เครื่องมือ 15 ตัว, การอนุมัติ, การสำรองไฟล์,
  ทะเบียนงาน, คิวข้อความ) เพราะส่วนนั้นตรวจสอบแล้วว่าทำงานจริง — เขียนใหม่เฉพาะ "หน้าจอ"

## กติกาที่เขียนไว้ในโค้ด (ไม่ใช่แค่ในเอกสาร)

- **เห็นทุกขั้น**: สถานะในแถบหัวและแถบสถานะสดมาจาก `ActivityCenter` ที่กินเหตุการณ์จริงจาก Agent เท่านั้น
- **ไม่ปดตัวเลข**: ใช้เวลาแสดงเป็นนาฬิกาที่เดินจริง ไม่มีการประมาณเวลาที่เหลือ/ความมั่นใจ
- **ย้อนกลับได้จริง**: ชีตรายละเอียดเรียก `WorkspaceBackup.restore` จริง และบอกถ้าทำไม่ได้เพราะอะไร
- **อนุมัติครั้งเดียว**: ชีตขออนุมัติให้เลือก "ครั้งนี้ / ไม่อนุญาต" และติ๊กยืนยันเพิ่มเมื่อเป็นการลบ
- **ไม่มีปุ่มหลอก**: งานตามเวลาถูกบอกว่า "ยังไม่มีในเวอร์ชันนี้" เพราะ iOS 15 ทำไม่ได้จริง
- **ไม่มีสปินเนอร์เปล่า**: ใช้ข้อความ + โครงร่าง (`AGSkeleton`) แทนทุกจุดที่รอ
- **คิวระหว่างทำงาน**: พิมพ์ระหว่าง Agent ทำงานได้ ขึ้นเป็นแถวเหนือช่องพิมพ์ และมีปุ่ม "ส่งเลย" หลังงานหยุด
- **หยุดกลางทางจริง**: เมื่อ iOS ระงับงานเบื้องหลัง แอปจะบอกตรง ๆ และให้ "ทำต่อจากจุดเดิม" ด้วยบริบทเดิม

## รอบเทียบแบบ (parity) — ตรวจจาก CSS/JS ของแบบทีละค่า

รอบนี้รื้อจุดที่ไม่ตรงกับแบบโดยตรง (ไม่ใช่การเดา):

| จุด | แบบว่าไว้ | แก้เป็น |
|---|---|---|
| มุมบับเบิล | `18px 18px 6px 18px` (มีหางมุมขวาล่าง) | `AGBubbleShape` ทำหาง 6pt แล้ว |
| ช่องพิมพ์ | `border-radius: var(--r-xl)` = 28px | เปลี่ยนจาก Capsule เป็นมุม 28 |
| ปุ่มไมค์ | อยู่ในช่องพิมพ์ (ด้านขวา) | ย้ายเข้าไปในช่องพิมพ์ เปิดชีตโหมดเสียง |
| ขอบวงกลมสถานะ | มีขอบ ยกเว้น keadaan สำเร็จ/กำลังทำ/ล้มเหลว | `AGStatusGlyph` ตรงตามนั้น |
| ป้ายในแถวขั้น | chip "กำลังทำ/ล้มเหลว/ข้ามไป/รอคิว" นำหน้าคำอธิบาย | เพิ่มแล้วใน `AGStepRow` |
| หัวการ์ดไทม์ไลน์ | "ทำงาน N ขั้นตอน" / "กำลังทำงาน N ขั้นตอน" + meta "· เวลา · N ขั้นผิดพลาด" | ใช้ข้อความและรูปแบบเดียวกัน |
| คำใบ้ท้ายการ์ด | "แตะขั้นตอนใดก็ได้เพื่อดูรายละเอียด · ระบบจะพับให้อัตโนมัติเมื่อจบงาน" | เพิ่มแล้ว |
| "กำลังคิด" | การ์ด `.tl.always` กางเสมอ + ข้อความเรืองแสง (ไม่ใช่สปินเนอร์) | `AGThinkingCard` + `AGShimmerLine` |
| แถบสถานะสด | แสดงเฉพาะตอนกำลังทำงาน + มีริบบิ้นอยู่ใต้แถบ | ตรงตามนั้น (เลิกแสดงหลังงานจบ — ผลงานอยู่ในการ์ดในแชท) |
| บรรทัดรองของแถบสถานะสด | ซ่อนในระดับ "น้อย" และ "ปกติ" | แสดงเฉพาะระดับ "ละเอียด" |
| สถานะว่าง | คำทักทาย + การ์ดความสามารถ 4 ใบ + แถบความปลอดภัย | `AGChatEmptyState` |
| ข้อความสถานะหัวจอ | idle/working/waiting ตามแผนที่ของแบบ (พร้อมตัวเลขจริง) | ใช้ "กำลังทำงาน · ขั้น N จาก M", "ทำงานเสร็จแล้ว · ใช้เวลา X", "มี N ขั้นที่ต้องให้คุณตัดสินใจ", "พร้อมทำงาน · ยังไม่มีงานค้าง" |
| ชีตขออนุญาต | "ขออนุญาต<สิ่งที่ทำ>" + แถบระดับความเสี่ยง + "จะทำอะไร" + "ผลที่ตามมา" + ช่องติ๊ก "ฉันเข้าใจว่าไฟล์นี้จะถูกลบและไม่มีสำเนา" + ปุ่ม เก็บสำรองแทน/แก้ไขก่อน | ทำครบ และปุ่มทั้งสองต่อกับการทำงานจริง (ปฏิเสธ + สั่ง Agent ใหม่) |
| แท็บ | แชท · ไฟล์ · งานของฉัน · ตั้งค่า (ย้ายบันทึกเข้าไปข้างใน) | ตรงตามนั้น + ทางเข้า "บันทึกการเรียกใช้" ในแท็บงานของฉัน |

**ข้อที่จงใจไม่ทำตามแบบ (เพราะทำแล้วจะเป็นการหลอกผู้ใช้):**
- ปุ่ม "อนุญาตเสมอ" และหน้าจัดการเพิกถอนสิทธิ์ — เอนจินยังไม่มีระบบนั้น (ถามใหม่ทุกครั้ง) จึงไม่แสดงปุ่มที่กดแล้วไม่มีผล
- สวิตช์แจ้งเตือนแบบแยกประเภท (เสร็จ/รอคำตอบ/ล้มเหลว/ความคืบหน้า) — ตัวส่งแจ้งเตือนมีสวิตช์เดียวจริง จึงแสดงเท่าที่มี
- งานตามเวลา — iOS 15 ทำไม่ได้จริง จึงบอกตรง ๆ ในหน้าแทนการโชว์ปุ่ม
