Event Data Structure (TypeScript)
interface AgentEvent { id: string; seq: number; parent_id?: string; type: 'thinking' | 'web_search' | 'browse' | 'read_file' | 'write_file' | 'run_code' | 'connector' | 'subagent' | 'plan' | 'ask_user' | 'permission'; status: 'pending' | 'running' | 'waiting_user' | 'succeeded' | 'failed' | 'skipped' | 'cancelled'; title: { th: string; en: string }; detail?: { th: string; en: string }; started_at: string; // ISO 8601 ended_at?: string; // ISO 8601 progress?: number; // 0 - 100 requires_approval: boolean; reversible: boolean; sensitivity: 'none' | 'personal' | 'financial' | 'credentials'; sources?: { id: string; domain: string; url: string; favicon_url?: string }[]; artifacts?: { id: string; file_type: string; file_name: string; file_size?: number; url?: string; created_at: string }[]; error?: { code: string; user_message: { th: string; en: string }; retryable: boolean; }; }

Lifecycle & Reconnect

Lifecycle: started → updated → completed / failed / skipped / cancelled. Reconnect: ส่ง event ซ้ำด้วย seq เดิม — ไม่สร้างซ้ำ. Unknown event: แสดงเป็นขั้นตอนทั่วไปโดยไม่ crash.

Edge Cases (6 กรณี)
  1. ไม่มี progress — ไม่แสดงเปอร์เซ็นต์ใน Timeline (แสดงเฉพาะสถานะ)
  2. ไม่มี sources — Web Search Card ไม่แสดง chip แหล่งข้อมูล
  3. ไม่มี artifacts — File Card ไม่ปรากฏใน Detail Sheet
  4. ไม่มี user_message ใน error — ใช้ข้อความเริ่มต้น "เกิดข้อผิดพลาดที่ไม่ทราบสาเหตุ — ลองใหม่อีกครั้ง"
  5. parent_id มีอยู่ — แสดงเป็นเลนย่อย (sub-agent); ความคืบหน้าหลัก = ค่าเฉลี่ยงานย่อย
  6. reversible = false — ไม่แสดงปุ่ม Undo; ถ้าผู้ใช้กด → แสดงข้อความ "ไม่สามารถย้อนกลับได้"
เหตุผลการตัดสินใจสำคัญ (7 ข้อ)
1
ไม่ใช้อิโมจิใน UI ทั้งหมด

อิโมจิทำให้ UI ดูไม่เป็นมืออาชีพและไม่เหมาะกับแอปที่จัดการข้อมูลส่วนตัว — การใช้ SVG stroke + ข้อความภาษาไทยให้ความรู้สึกเป็นระบบและชัดเจนกว่า ไม่ขึ้นอยู่กับ font อิโมจิของระบบ

2
Agent message ไม่มี bubble (อ่านแบบเอกสาร)

การไม่ใช้ bubble สร้างความแตกต่างจาก ChatGPT clone และทำให้ข้อความ Agent อ่านสบายขึ้น (line-height 1.7) — progressive disclosure (Timeline + Detail Sheet) ทำงานได้ดีกว่าเมื่อข้อความไม่ถูกจำกัดด้วย bubble width

3
ใช้สี Warm Amber (#B07A2A) แทนสีฟ้า/ม่วง AI

สีฟ้าและม่วงเป็นเอกลักษณ์ของ ChatGPT, Claude, Gemini — การใช้ amber สื่อถึง "อบอุ่น เป็นกันเอง" และลดความเครียดเมื่ออ่านข้อมูลที่ซับซ้อน ไม่ถูกเข้าใจผิดว่าเป็น clone

4
ไม่แสดงตัวเลขประมาณการเมื่อไม่มีข้อมูลจริง

การแสดงตัวเลขที่ไม่มีข้อมูลรองรับทำให้ผู้ใช้เข้าใจผิดและลดความน่าเชื่อถือ — ระบบแสดงเฉพาะสถานะ "กำลังทำ" และความคืบหน้าเปอร์เซ็นต์ (ถ้ามีข้อมูล)

5
Timeline ใช้ vertical connector line แทน card แยกกัน

เส้นเชื่อมสร้างความรู้สึกว่า "ขั้นตอนเหล่านี้เป็นงานเดียวกัน" และลดพื้นที่ในแนวตั้ง (ไม่ต้องมี margin ใหญ่ระหว่าง card) — อ่านง่ายกว่าแม้มี 6-8 ขั้นตอน

6
Detail Sheet แยกเป็น bottom sheet ไม่แสดงใน Timeline

ข้อมูลเทคนิค (แหล่งข้อมูล, โค้ด, ข้อผิดพลาด) มีความยาวและซับซ้อน — ถ้าแสดงใน Timeline จะทำให้ Timeline ยืดและอ่านยาก — progressive disclosure (แตะ citation เพื่อเปิด) ทำงานได้ดีกว่า

7
ทุกข้อความที่ผู้ใช้เห็นเป็นภาษาไทยธรรมดา (ไม่ใช้ศัพท์เทคนิค)

ผู้ใช้เป้าหมายไม่ใช่โปรแกรมเมอร์ — การใช้ "กำลังค้นหาเว็บ" แทน "invoking web_search tool" ทำให้ผู้ใช้เข้าใจและรู้สึกควบคุมได้จริง ไม่รู้สึกว่าเป็นแค่ผู้สังเกตการณ์
